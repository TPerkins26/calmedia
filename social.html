🎮 Discord Bot Integration Architecture

How Discord server members, slash commands, and interaction webhooks interface with CalMedia.

Live Gateway Webhook Endpoint

POST /api/discord/webhook

Compatible with standard Discord Interaction Webhooks, Discord.py, and Discord.js bots. Accepts JSON payloads containing sender_id, content, and optional attachment_url.

Supported Commands (Prefix ! or /):

  • !agenda [date] — Queries your calendar for today's classes and meetings.
  • !free [@friend/ALL] — Runs set intersection to find mutual free windows.
  • !meet @friend [HH:MM-HH:MM] [title] — Checks pre-flight conflicts and books directly into local calendar stores.
  • !privacy [BUSY/OPEN] — Toggles whether friends see event titles or masked busy blocks.
  • Photo Attachments — Attaching an image anchors it to your active event and posts it to the campus moments feed.
